# Small cell vote

Live class vote for INFO 5410: where should one new small cell go in the South Bronx?

- `/` ballot for students (pick one of nine sites, give a 1–3 word reason)
- `/results` projector page: map bubbles sized by votes, word cloud coloured by site

Run locally: `node server.js`, then open http://localhost:3000.

Deploy: Render → New → Blueprint → pick this repo. `ADMIN_KEY` is generated by Render
(Environment tab); use it with the small "reset" link on `/results` to clear votes.

Votes live in memory and a local file, so a restart of the free instance clears them.
